## 0. Обязательный шаг в Supabase — сделать в первую очередь

Без этого подборки не создаются (ошибка "row-level security policy"). SQL Editor → вставить → Run:

```sql
alter table collections disable row level security;
alter table agents disable row level security;
```

(Вторая строка — если вдруг ещё не выполняли раньше; если уже делали, ошибки не будет, просто ничего не изменится.)

## 1. Три вида страницы одного объекта

У каждого объекта теперь есть 3 разных адреса — показывают разное в зависимости от того, кто смотрит:

| Адрес | Кто смотрит | Что видно |
|---|---|---|
| `/p/<id>` | Клиент | Фото, цена, характеристики, описание, документы (список), видеообзор, похожие объекты внизу, контакты агента RAYAN. НЕ видно: комиссию, собственника, точный адрес |
| `/a/<id>` | Другой агент (не свой объект) | То же что клиент + статус объекта, "Рабочая информация" (комиссия, в руки, комментарий), кнопки "Добавить в подборку" и "Поделиться". НЕ видно: сканы документов, номер и адрес собственника |
| `/listing/<id>` | Вы / договорник (свой объект) | Всё целиком: редактирование, статусы, собственник, точный адрес, финансы, удаление |

**Как получить эти ссылки на реальном объекте:** откройте любой объект как обычно (`/listing/<id>`) →
там два зелёных/золотых блока: "Для клиента" (копирует `/p/...`) и "Для коллеги-агента" (копирует `/a/...`).

**Проверить:** откройте один и тот же объект всеми тремя способами подряд, сравните, что видно на каждой.

## 2. Личный кабинет агента

Вход — без пароля (сознательно, временно): низ меню → «Профиль» → ввести рабочий номер телефона.
Работает пока для одного агента — Насреддина (`+996701229133`). Чтобы завести кабинет ещё кому-то —
одна строка в Supabase (SQL Editor):

```sql
insert into agents (name, phone, whatsapp) values ('Имя Фамилия', '+996XXXXXXXXX', '+996XXXXXXXXX');
```

**В кабинете:** имя, телефон, "Мои объекты" (находятся автоматически по номеру телефона в объекте — то
есть объект "мой", если в его поле "Телефон агента" стоит именно этот номер), "Мои подборки".

**Важно про номер при отправке клиенту — то, что вы спрашивали:** сейчас, если Насреддин зайдёт в кабинет
и откроет объект, а потом скопирует клиенту ссылку — там будет номер **того агента, который указан в самом
объекте** (поле "Телефон агента" при заполнении формы), а не автоматически номер Насреддина, даже если это
он сейчас в кабинете смотрит. Отдельной функции "мой номер вместо номера в объекте" — **ещё не существует**,
это то, что мы обсуждали как "поделиться с заменой номера и ценой" и не закончили. Проверять её пока нечего —
её физически нет в коде. Это следующая задача, отдельно от личного кабинета.

## 3. Подборки

На странице `/a/<id>` (вид агента) — кнопки "Добавить в подборку" и "Поделиться" рядом, зелёные.

**Как проверить:**
1. Откройте любой объект как агент (`/a/<id>`)
2. "Добавить в подборку" → "Название новой подборки" → впишите любое → "Создать и добавить"
3. Откройте ещё один объект, тем же способом добавьте его в ТУ ЖЕ подборку (она появится в списке "недавние")
4. В личном кабинете, в "Мои подборки" — должна появиться, с количеством объектов и иконками WhatsApp/Telegram/MAX для быстрой отправки
5. Откройте подборку по ссылке (`/c/<id>`) — список объектов

**Чего в подборках пока нет** (следующая задача, ещё не начата после сегодняшних правок):
персонально поменять цену/описание конкретно для этой подборки (чтобы отправить клиенту дороже своей
наценкой, или убрать случайно попавший в описание чужой номер) — то, что мы подробно обсуждали, но не
успели построить.

## 4. Видеообзор

При заполнении/редактировании объекта, сразу после фото — блок "Видеообзор объекта", три кнопки
(YouTube/Telegram/Instagram), после выбора — поле для ссылки с проверкой формата. Кнопка "▶ Видеообзор"
после этого показывается на всех трёх видах страницы объекта (клиент/агент/договорник).

## 5. Главная страница

Картинки категорий — готовы для Квартир, Новостроек, Домов, Участков, Коммерческой, Аренды. Ждут картинок:
Иссык-Куль, Инвестиции. Счётчик "Новые" — считает по дате публикации ИЛИ по дате создания записи, смотря
что раньше сработает.
