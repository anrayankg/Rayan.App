RAYAN — Будущие интеграции и Центр рекламы
Ничего из этого не реализовано и не начато. Это фиксация требований на будущее.
Центр рекламы
Отдельный раздел "Реклама". Главная кнопка "Запустить рекламу" — зелёная, с золотым фирменным акцентом.
Показывать площадки с реальными логотипами (не просто текст): Lalafo, House.kg, Instagram, Facebook, TikTok, Threads, Telegram, WhatsApp.
Для каждой пары (объект × площадка) хранить: площадку, объект, ссылку на объявление, статус, дату и время публикации, последнее рекламное действие и его дату, следующее запланированное действие, статус (активно / требует рекламы / просрочено), историю действий.
"Просрочена реклама" ≠ объект просрочен. Означает: наступила дата следующего запланированного рекламного действия (например, обновлять каждые 3 дня), а агент его не выполнил.
Утренний список агента
Агент открывает приложение и видит "Сегодня нужно прорекламировать: N объектов" со списком, который можно пройти последовательно. Приложение само считает, что требует действия сегодня.
Площадки — для каждой сначала исследовать официальный API, ничего не придумывать
Для каждой из: Lalafo, House.kg, Instagram, Facebook, TikTok, Threads, Telegram (Bot API/Business), WhatsApp Business Platform — нужно выяснить: публикация, обновление, поднятие объявления, смена фото/описания, получение ссылки, получение сообщений/комментариев, ответы из RAYAN, статистика, ограничения, необходимые права доступа.
Принцип: А — автоматизация, если официальный API разрешает. Б — удобный ручной сценарий (открыть площадку → нужный объект → подготовленный текст/фото → агент делает сам), если официальной возможности нет. Никогда не использовать неофициальные обходы блокировок и не обещать автоматизацию без подтверждённой технической возможности. Главное — не плодить дубли объявлений, если существующее можно обновить.
Единый центр сообщений ("Чаты")
Собирать сообщения/комментарии со всех подключённых площадок в одном месте. Каждое сообщение связано с: площадкой, объектом, клиентом, датой, временем, текстом, статусом прочитано/не прочитано.
Ответы из RAYAN — только если официальный API это разрешает; иначе кнопка просто открывает нужный диалог на самой площадке.
Связь объекта с рекламой
У каждого объекта в будущем — рекламная история по каждой площадке отдельно: публикация → ссылка → дата → последнее действие → следующее действие → статистика/комментарии.
Будущая система задач агента
"Сегодня нужно рекламировать: N", "Просрочено: N", "Реклама выполнена: N" — с историей по датам, площадкам, действиям и результатам.
