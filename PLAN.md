# RAYAN — план проекта

Этот файл — источник правды по плану. Если начинается новый чат с Claude:
дай ссылку на этот репозиторий и попроси сначала прочитать PLAN.md.

## Видение
Приложение для риэлторского агентства в Бишкеке с AI-ассистентом: агент
создаёт объект прямо на встрече с телефона, ассистент помогает с описанием,
дальше — поиск, подбор клиентам, публикация на площадках.

## Правила, которые нельзя менять без согласования с Айгуль
- Локации — это рыночная логика Бишкека (справочник lib/locations.js), а
  НЕ только официальные районы. Новые названия районов не придумываются.
- Карточка объекта = 4 блока: Публичная информация / Информация для агента
  (в руки, комиссия, точный адрес) / Документы / Договор.
- Статус договора (contract_status) — отдельное поле, не по наличию файла.
- ID объекта — автоматический (RAYAN-000001), вручную не присваивается.
- Телефон/данные собственника видят только агент-договорник, РОП, директор/админ.
- AI может писать продающий текст, но не имеет права менять факты (адрес,
  цена, номер договора, характеристики).

## Этап A — форма создания объекта «Вторичка» (готово)
Поля, фото объекта/документов, блок «Договор», карта с точкой, отправка
на проверку. Остальные типы объектов (Первичка, Дом, Участок, Коммерция,
Аренда, Иссык-Куль, Инвестиции) по этому же образцу — ещё не сделаны.

## Дальше по плану
- **Этап B** — экран «Карточка объекта» (просмотр). Фундамент для C.
- **Этап C** — публичная страница объекта без входа.
- **Этап D** — личный кабинет клиента (регистрация телефон+WhatsApp
  раздельно, избранное, уведомление агенту).
- **Этап E** — AI-описание и AI-обложка объекта (нужен платный AI API —
  отдельное решение по бюджету).
- **Этап F** — автоподбор объектов: соседние районы + бюджет ±15%.
  Самая сложная логика, поэтому в конце.
- Отдельно, не блокирует остальное: визуальный редизайн под стиль Lalafo
  (шрифты/цвета/кнопки), кроме главной страницы.
